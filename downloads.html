    Install
    
        
      
          
    1. Windows: unzip the download into a folder of your own, such as Documents\SPIDER, and start SPIDER.exe. If Windows says the publisher is unknown, choose More info, then Run anyway. Releases are not code-signed yet.
      2. 
          
    2. Linux: unpack the .tar.gz into a folder of your own (tar -xzf SPIDER-*.tar.gz) and start SPIDER.x86_64.
      3. 
          
    3. For wireless robots, install Python 3 from python.org. S.P.I.D.E.R. adds the one package it needs when you switch Bluetooth on.
      4. 
          
    4. Follow the how-to guides to connect your first board.
      5.
