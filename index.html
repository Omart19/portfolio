Software · robotics

S.P.I.D.E.R.

A command center for robots: SBC & Peripheral Interface for Drone Engineering & Robotics. It flashes ESP32 boards with its own flasher, connects them over Bluetooth with no pairing, gives every robot a live 3D twin, and puts a control deck on screen that you can drive with a gamepad or program in Python, C# or C++.

Built with
Godot 4.7 · .NET · its own ESP32 flasher
Connects
USB, Wi-Fi, Bluetooth LE
Also has
Code editor with live checking, dockable windows, a fly-brain neural lab
Status
In development · early access

Hardware · robots

Robot builds

The robots S.P.I.D.E.R. was made for. Each one starts as a build sheet, gets wired on the bench, and is driven from the dashboard over Bluetooth. A servo rig on an ESP32-S3 runs today; a four-legged walker, a six-legged walker and a drone are in the works.

How a project moves

Process

01

Design

Pin down what it has to do and sketch how it should look and work.

02

Model

Build it in 3D first: the parts, how they fit, how it looks in motion.

03

Build

Write the code, wire the electronics, flash the boards, put it together.

04

Prove

Test it hard. Bots play the game, robots run on the bench, until it holds up.
